# pkh 기온 데이터 프로젝터
# 🌡️ Same-Day Temperature Comparison Dashboard

본 프로젝트는 **일별 기온 시계열 데이터**를 활용하여  
특정 날짜가 **과거 같은 월-일 기준으로 얼마나 춥거나 더웠는지**를  
직관적으로 비교·시각화하는 **Streamlit 기반 웹 애플리케이션**입니다.

기본 데이터가 앱에 탑재되어 있으며,  
**동일 형식의 CSV 데이터를 추가 업로드하면 자동으로 통합 분석**됩니다.

---

## 1. 프로젝트 목적

- 특정 한파·폭염일이 **역사적으로 어느 수준인지 설명**
- “평년 대비 얼마나 다른가”를 **정량적 지표로 제시**
- 교육·연구·보고용으로 **재현 가능한 데이터 기반 비교 환경 제공**

---

## 2. 주요 기능

### ① 기본 데이터 + 추가 데이터 자동 결합
- 기본 CSV 파일을 앱에 **기본 탑재**
- 동일 형식의 CSV 파일 업로드 시
  - 자동 인코딩 처리
  - 컬럼 정규화
  - 날짜·지점 기준 중복 제거 후 병합

### ② 같은 월-일 기준 기온 비교
선택한 날짜(미선택 시 **가장 최근 날짜**)의 기온을 다음 기준으로 비교합니다.

- 같은 월-일의 **역사적 평균 대비 차이(℃)**
- 같은 월-일 분포에서의 **퍼센타일(percentile)**
- **Z-점수(Z-score)** 기반 이례성 판단
- 자기 연도 포함 / 제외 기준 모두 제공

> 예시  
> *“2024-01-22 평균기온은 과거 같은 날짜 대비 평균보다 +2.1℃ 높으며,  
> 상위 85퍼센타일에 해당합니다.”*

---

### ③ Plotly 기반 인터랙티브 시각화
모든 그래프는 **Plotly**로 구현되어 확대·축소·툴팁 확인이 가능합니다.

- 같은 월-일 **연도별 기온 추이(Line)**
- 같은 월-일 **분포(Boxplot + 점 표시)**
- 최근 3년 **연속 시계열 그래프**

---

### ④ 데이터 품질 요약
- 선택 지점 기준 변수별 **결측치 개수 및 비율 자동 표시**
- 장기 기후 데이터 특성을 고려하여 **이상치 제거는 수행하지 않음**

---

## 3. 데이터 형식

업로드되는 모든 CSV 파일은 아래 컬럼을 포함해야 합니다.

| 컬럼명 | 설명 |
|---|---|
| 날짜 | YYYY-MM-DD 또는 YYYYMMDD |
| 지점 | 지점 코드(정수) |
| 평균기온(℃) | 일 평균기온 |
| 최저기온(℃) | 일 최저기온 |
| 최고기온(℃) | 일 최고기온 |

※ 컬럼명에 일부 변형이 있어도 자동으로 정규화됩니다.
